# Study evidence

The compact evidence files of the [Abstraction ladder study](../README.md) kept in the repository: the score table and the run manifest of each scored run, and the bundle and archive checksums that tie them to the raw run bundles. The raw transcripts and bundles stay outside the repository and are cited by checksum.

The score tables and manifests of study 1's runs, `study-1/` and `gamma-prime-1/`, are byte copies of the files in the run folders, taken from a copy verified against the archive's per-file sums on 2026-10-21. A Windows checkout may hold them with CRLF line ends; their checksums are of the LF bytes the run wrote. The [analysis](../analysis/README.md) refuses to run when its copies of the run folders differ from these files or from these checksums, and its tests check these files against `checksums.json`. The `commit` field of these two run manifests is a lab commit: the commit of the original lab repository, where the harness ran, not a commit of this repository.

The score table and manifest of study 2's scored run, `study-2/`, are byte copies of the files in the run folder, taken from a copy verified on 2026-11-07 against the run's per-file sums file `SHA256SUMS-study2-scored-1`, with the bundle checksum and status checked as well. `study-2/checksums.json` holds their checksums, of the LF bytes the run wrote. The [study 2 analysis](../analysis2/README.md), `analyze2.py`, checks its own copy of the run folder against that sums file and the bundle checksum before it computes anything; it does not read these committed files. The `commit` field of this manifest, `32e6b828d53a8f09bab55eff1a5703a65d50be58`, is a commit of this repository, where the harness ran.

The score table and manifest of study 3's scored run, `study-3/`, are byte copies of the files in the run folder, taken from a copy verified on 2026-11-25 against the run's per-file sums file `SHA256SUMS-study3-scored-1.txt`, with the bundle checksum and status checked as well. `study-3/checksums.json` holds their checksums, of the LF bytes the run wrote. The [study 3 analysis](../analysis3/README.md), `analyze3.py`, checks its own copy of the run folder against that sums file and the bundle checksum before it computes anything; it does not read these committed files. The `commit` field of this manifest, `37124bdb3767d8f244e14c3c28832006a7e5b3ea`, is a commit of this repository, where the harness ran.
